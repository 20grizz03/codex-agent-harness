# Краткое описание PR

Описание PR — один короткий абзац из одного-двух предложений. Пиши по фактическому diff:

1. Что изменено в рамках задачи и какое наблюдаемое поведение появилось.
2. Важная граница, совместимость или способ обработки ошибки, если без него описание неполно.

Пример формы:

```text
Добавил фильтр каталога по категории до пагинации. Неизвестная категория возвращает ошибку валидации; запрос без фильтра сохраняет прежний формат ответа.
```

Не пересказывай постановку, не перечисляй каждый файл и не добавляй рекламные формулировки. Проверки и рекомендации к тестированию выноси в предназначенные для них поля, если шаблон репозитория не требует иного. Не добавляй `Co-Authored-By`, упоминание AI или другие маркеры машинного авторства.

По умолчанию подготовь текст для пользователя. Публикуй или изменяй PR только по отдельной явной просьбе.
